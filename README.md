# AtmosView

**Cross-platform weather application for Windows and Android.**

AtmosView is a modern weather application focused on detailed forecasts, a clean interface, and a customizable user experience.

## Technologies

*The technology stack is being established.*

- TypeScript
- React
- Vite
- ESLint
- Open-Meteo API (planned)

## Planned Features

- Current weather conditions
- Detailed hourly and daily forecasts
- Weather charts and visualizations
- Multiple saved locations
- Weather alerts and notifications
- Customizable dashboard
- Dark atmospheric interface

## Platforms

- Windows — planned
- Android — planned

## Development

The project is currently in its initial development stage.

### Getting Started

Clone the repository:

```bash
git clone https://github.com/Fllorovi/AtmosView.git
cd AtmosView
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Run the linter:

```bash
npm run lint
```
